The platform

Everything you need to ship agents with confidence.

From the first prompt to the millionth production run — Vexel handles planning, execution, evaluation, and observability in one runtime.

{ }

Define agents in code, not strings.

Compose tools, retrieval, and reasoning into typed graphs. Vexel handles retries, branching, and rollbacks — you write the logic.

from vexel import Agent, Tool, plan   # Compose deterministic, traceable agents agent = Agent(   name="triage-bot",   reasoner="vexel/reasoner-3",   tools=[Tool.search(), Tool.crm(), Tool.handoff()],   eval="datasets/golden-tickets", )   result = await agent.run(ticket, trace=True)
